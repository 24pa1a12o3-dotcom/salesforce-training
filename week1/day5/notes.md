
# Day 5 Notes - Apex Introduction

# What is Apex?

Apex is a strongly typed, object-oriented programming language developed by Salesforce. It is used to implement custom business logic and advanced automation.

---

# Why Apex is Needed

Flows and configuration tools are useful for simple automation, but some requirements need coding.

### Examples
- Complex calculations
- API integrations
- Advanced validations
- Batch processing

---

# Flow vs Apex

## Flow
- No-code or low-code
- Easy to configure
- Best for simple automation

## Apex
- Programming-based
- Handles complex logic
- Supports integrations and advanced processing

---

# Configuration vs Coding

## Configuration
Uses Salesforce built-in tools.

### Examples
- Validation Rules
- Flows
- Formula Fields

## Coding
Uses Apex and Lightning components.

### Examples
- Custom APIs
- Advanced business rules
- External system integration

---

# Real Examples Where Apex is Used

1. Online payment integration
2. Scholarship eligibility processing
3. Attendance monitoring system
4. Bulk student data processing
5. Complex admission workflows

---

# Pseudocode Concept

Pseudocode helps developers design logic before writing actual code.

### Example
IF fee is unpaid  
THEN send notification

---

# Importance of Apex

- Provides flexibility
- Supports enterprise-scale applications
- Enables advanced customization
- Helps automate complex processes
