
# Day 2 - Platform Basics Core Task

## Task 1: CRM and Salesforce Platform

### How CRM Concepts Fit into Salesforce Platform

Salesforce uses CRM concepts to manage customer relationships and business processes.

- Account represents a company or organization.
- Contact represents people associated with an account.
- Opportunity represents a potential business deal or sales process.

These concepts are managed using Salesforce Objects and Apps.

### Example
- Account → ABC Company
- Contact → John Smith
- Opportunity → Software Purchase Deal

# Task 2: Platform Understanding

## What is an App in Salesforce?
An App in Salesforce is a collection of tabs, objects, and features designed for a specific business process.

### Examples
- Sales App
- Service App

---

## What is an Object?
An Object is a database table used to store records and data in Salesforce.

### Types of Objects
1. Standard Objects
   - Account
   - Contact
   - Lead

2. Custom Objects
   - Student
   - Patient

---

## What is a Tab?
A Tab is a user interface element that helps users access objects, records, and applications easily.

### Examples
- Account Tab
- Contact Tab

---

# Task 3: Thinking Task

## When should we use Configuration (No Code)?

Configuration is used when requirements can be implemented using Salesforce built-in tools.

### Examples
1. Creating Validation Rules
2. Building Flows for automation

---

## When should we use Coding (Apex)?

Coding is used for advanced or complex business logic that cannot be handled by configuration alone.

### Examples
1. Complex calculations using Apex
2. Custom integrations with external systems
