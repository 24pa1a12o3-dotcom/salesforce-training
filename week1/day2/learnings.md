
# Day 2 Learnings

## Topics Learned
- Introduction to Salesforce Platform
- Understanding Apps, Objects, and Tabs
- Difference between Configuration and Coding
- Basics of Multi-Tenant Architecture
- System Design Thinking

---

## Key Learnings
- Salesforce is a cloud CRM platform.
- Apps organize business functionalities.
- Objects store records and data.
- Tabs provide navigation in Salesforce.
- Configuration is faster for simple automation.
- Coding is useful for advanced customization.

---

## Practical Understanding
I learned how Salesforce combines low-code tools and programming to build scalable business applications.
