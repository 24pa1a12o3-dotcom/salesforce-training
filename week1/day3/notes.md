
# Day 3 Notes - Salesforce Data Modeling

## App
A collection of tabs and objects for a business process.

## Object
A database table that stores records.

### Types
- Standard Objects
- Custom Objects

## Record
A single row of data inside an object.

## Field
A column in an object used to store information.

---

# Standard vs Custom Objects

## Standard Objects
Provided by Salesforce by default.

### Examples
- Account
- Contact
- Lead

## Custom Objects
Created based on business needs.

### Examples
- Student
- Faculty

---

# Relationships in Salesforce

## Lookup Relationship
Connects two objects loosely.

## Master-Detail Relationship
Strong parent-child relationship.

---

# Formula Fields
Used for automatic calculations.

### Examples
- Full Name
- Percentage
- Remaining Seats

---

# Validation Rules
Used to prevent incorrect data entry.

### Examples
- Email mandatory
- Age cannot be negative
- Seats cannot exceed limit
